# ⚡ 思源语音 · Voice Notes（Lite 轻量版）

已有课程字幕或会议逐字稿时，可以直接把音频和字幕一起放进思源。Lite 安装包约 **11.4 MiB**，不含识别模型。打开笔记就能按句回听，也能只留原音，听到重点时再做标记。

## 把 SRT / VTT 字幕放到录音时间轴上

点文档上方的声波图标，选择「导入音频」，一起选中录音和同名字幕。每句字幕都按起止时间排好，点一句就能听到那段原音。字幕里已有的人名（例如句首的 `[王老师]`）可以转成人物色带。没有人名时，也可以边听边补。

![导入一条录音和同名字幕，展开逐字稿按句回听](https://gcore.jsdelivr.net/gh/jiangeeeeee/siyuan-voice-notes-lite@9ee74b340d2fc1d8f922ea37599c3b5c27223950/docs/demos/import.gif)

- **🎙️ 录下现场或线上会议。** 平时可用麦克风，开会时可在「会议录音」里选系统声音，或同时录下自己和对方。可选声源取决于系统和浏览器。在支持的桌面浏览器中，共享会议标签页时勾选共享音频即可录下对方的声音。
- **在波形上精准打点。** 按住 Alt（Mac 用 Option）点击波形，就能在那个时刻添加时间标签。例如老师开始讲第二种解法时，标上“解法二”，复习时从这里听起。
- **🔗 把原话引到正文。** 用 Pro 在波形上选定起止位置，复制这段原音的链接，贴到会议结论旁。点链接就能回听当时的讨论。

## Lite、Full 与 Pro 怎么选

Lite 适合录音、回听和整理现成字幕。要让思源离线转写、只重转某一句，或按声音自动区分发言人，请选自带模型的 [Full 版](https://github.com/jiangeeeeee/siyuan-voice-notes)。启用 Pro 后，Lite 仍使用导入的字幕或手工录入的逐字稿。

- **Free** 可录音、导入音频和字幕、按句回听、编辑逐字稿、手动区分发言人和改名，也可加时间标签、导出文字。
- **Pro** 可将正文与录音中的时间段建立双链，用专业词库批量纠错，或裁剪多个音频片段并试听拼接效果。
