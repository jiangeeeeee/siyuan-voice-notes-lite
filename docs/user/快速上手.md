# 思源语音快速上手

2026-11-13 同版本修订：新增音轨发言人右键变更/清除及自动分析人数设置。详见[发言人识别与修正](发言人识别与修正.md)。

适用版本为 0.9.0。Lite 可完成录音、导入、字幕和手动整理；本地自动识别需要 Full，第二模型组件目前为 Windows x64。

1. 在思源正文中点击想放录音的位置，再点面包屑的麦克风。
2. 选择“开始录音”，或“导入音频”。录音时点右下角录音按钮打开控制；隐私模式从面包屑选择“打开录音控制”。
3. 会前可点“会前设置参会人”，每行一个姓名。录音中点“变更发言人”选择当前说话的人。
4. 点“结束录音”后生成语音块。用播放键、波形、前后 15 秒或时间输入定位。导入可同时选择同名 SRT/VTT/TXT 字幕。
5. 打开“显示转写”。Lite 用“手动添加转写”或导入字幕；Full 可生成逐字稿。每段的“批注与编辑”可以修改文字、人物、标签和批注。
6. 需要边听边记或边录边记时，开启“同步正文笔记与音频”或录音控制中的同步开关。这是 Pro 功能。正文出现右侧回听入口后，可以从那里回听。
7. 需要引用一句原话时，点“复制语音段链接”（Pro），粘贴到正文；也可先选中正文文字，再点工具栏“链接至语音”。
8. 语音块右上角“更多操作”→“逐字稿与校对”→“导出逐字稿”，选择是否带时间戳、发言人，再下载 TXT。

9. 按住 Ctrl（Mac 用 ⌘）拖选波形或勾选语段，点顶部「删除选中语音」。在播放器内按 Ctrl+Z 或 ⌘Z 即可恢复。

双击录音块左上角名称可改名；Label 的新建与编辑免费；专业词库与纠错需要 Pro。若播放异常，在「信息」核对音频路径，检查工作空间资源的同步状态。

详细说明、操作演示和恢复方法见 [使用手册](使用手册.md)。首次使用建议先试一段一分钟以内的录音，检查本机权限和声音能否正常回放。
