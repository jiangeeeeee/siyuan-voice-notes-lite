# 0.8.0 的验证范围

本轮使用 Windows x64、思源 3.8.9 隔离内核与 Chrome 157。没有修改日常工作空间，也没有发布到集市。

已经运行：TypeScript 检查、72 项单元测试、真实内核/浏览器集成测试。覆盖标记与批注保存时的媒体连续性、插入位置、正文同步与复制、引用及反向访问、人物切换和人工保护、草稿改位置恢复、词库校对与撤销、局部转写、九种实际编码音频导入、长列表分页。录音测试使用真实 MediaRecorder，输入来自测试 WAV 的假麦克风。

SenseVoiceSmall 与 Qwen3-ASR-0.6B 都实际运行了公开中、英、粤音频。第二模型使用空共享缓存的新进程测试，测试代码拒绝网络 socket 连接。浏览器复核界面通过测试传输连接真实 Qwen；生产子进程桥另行运行验证。没有经过人工核对的参考稿，因此没有识别准确率或双模型提升结论。

两小时压力样本是静音 WAV，10,000 条转写是生成的测试数据；它验证列表和播放定位，不验证两小时会议的识别质量。Pro 测试采用独立测试公钥和模拟账号，发行包保留原生产公钥。

用户选择暂时跳过桌面窗口验收。本轮没有完成真实麦克风、系统权限拒绝、断电/休眠、手机、macOS、Linux Full 或所有机器可读用例的全矩阵验收。不能把已通过的浏览器场景当成这些项目已通过。完整用例仍按 PASS、FAIL、BLOCKED、NOT_RUN、NA 分别保存。

Full 当前只提供 Windows x64 便携运行组件；其他平台请用 Lite 或已有逐字稿。双模型一次最多五分钟，提供双候选人工核对，不自动生成逐词对齐或融合“原话”。
