# 发言人识别与修正（0.9.0）

## 自动识别看什么

插件把音频转换为 16 kHz 单声道，使用 pyannote segmentation 3.0 找语音区间，
再用 3D-Speaker ERes2Net base 提取音色特征。sherpa-onnx 1.12.20 按特征的余弦距离做聚类。
插件再比较各区间的梅尔倒谱、基频分布、频谱形状和响度变化。带时间定位的文字提供用词与句长等辅助信息。在自动估计人数时，多段一致的样本可以支持拆分或合并原有分组；相邻话轮帮助判断个别归属。

点标题下的「识别发言人」开始分析。「声纹绑定」可选一段单人发言，试听后输入已有或新姓名，点「保存并重新识别」。同一人的多个样本会在后续录音中参与匹配。点人物标签即可改名，已绑定人物的名称在同一工作空间共用。播放位置和色带会提示已匹配的档案得分，分数接近时保留匿名编号。

## 人数分错时怎么调

1. 打开语音块的“更多操作 → 发言人 → 自动区分发言人”。
2. 知道实际有几个人讲话时，填写“实际发言人数”。填写的是实际出声的人数，不是参会名单人数。
3. 不确定时保留 0，表示自动估计。高级设置默认阈值 0.5；同一人被分成很多人可调大到 0.7，不同人被合并可调小到 0.3。不同录音需分别回听判断。
4. 点击“开始分析”。新结果替换旧的自动标注，人工改过的区间和语段会保留。相同时间位置的旧人物尽量按多数时间重叠复用，避免每次重跑新增一套匿名人物。

正文跨越不同人、存在交叠发言或标注未覆盖整句话时，会保留为混合/未指定，请回听后拆分或人工更正。
不会按“谁重叠得最多”直接认定整句话属于谁。

## 在音轨上右键修改

对音轨上方的某个发言人色条右键：

- **变更此段发言人**：选择已有的人，或输入新姓名。只修改这段时间，前后边界不变。
- **删除此段发言人标注**：清除这个时间段的标注，不向前一位发言人延长范围。音频、正文、批注、引用都保留。重新自动分析时可能再次生成该区间的标注。
- **编辑此发言人（改名、合并或删除）**：管理这个人物在整条录音里的记录。合并后的标注记为人工更正。

旧版只保存语段人物、没有音轨区间记录的录音，也可以右键，操作只作用于所选语段。
键盘聚焦色条后可用 Shift+F10 打开菜单。Ctrl/Command 点击原音引用范围的操作保持原样。
正文单句的人工更正优先；修改音轨人物不会覆盖这些更正。

## 速度与局限

首次分析仍需在本机 CPU 上处理完整录音；声学指纹也在本机提取。
模型在空闲时保留两分钟，随后自动释放；两分钟内相同音频内容和相同参数可复用分析结果。
修改参数仍要重新分析。关闭插件、取消或报错会释放对应资源。
整段已在录音过程中人工指定人物时，结束录音不再做无效的自动分析。

2026-11-13 在 Mac arm64 上，用官方 56.86 秒四人中文样本测试：
默认自动人数得到 7 类，指定 4 人得到 4 类；模型计算分别约 21.37 秒和 21.51 秒，
首次加载约 0.395 秒，复用模型配置约 0.0001 秒。
这些数字是一次样本的耗时与人数检查，不能证明每句话的发言人都判断正确，也不代表会议录音的准确率。

短促插话、远场、回声、相近音色和同时讲话仍可能误分。当前最实用的做法是填写已知人数，
再用右键修正局部结果。若要显著提高长录音首次分析速度，需要后续评估原生多线程推理或其他模型。
